# Materiales

Subí acá los archivos reales de cada clase (PDF de diapositivas, .csv/.xlsx
de datos, scripts .R/.py/.do). Usá el mismo nombre que referencian las
páginas de cada clase, por ejemplo:

- `clase-1-slides.pdf`
- `clase-1-datos.csv`
- `clase-2-slides.pdf`
- `clase-2-datos.csv`

Así los enlaces de `clases/clase-1/index.md`, etc. funcionan sin tocar nada más.
